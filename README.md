## ✨ Features

- **Cinematic User Interface:** A highly polished, editorial design system featuring glassmorphism, smooth Framer Motion animations, and ultra-premium typography.
- **AI Travel Concierge:** An integrated AI planner that crafts personalized travel itineraries and recommends destinations based on user preferences.
- **End-to-End Booking Engine:** Users can browse curated packages, select dates, and seamlessly checkout with interactive booking flows.
- **Secure Admin Dashboard:** A protected route for administrators to view live revenue metrics, manage bookings, and oversee the platform.
- **Live Weather Integration:** Real-time dynamic weather widgets for all destinations, powered by the Open-Meteo API.
- **Automated Email Receipts:** Beautifully designed HTML email confirmations generated via eact-email.
- **User Profiles & Wishlists:** Authenticated users can save their favorite destinations and view their past booking history.

## 🚀 Getting Started

First, clone the repository and install the dependencies:

`ash
git clone https://github.com/mohammednafees302/zyrotrip.git
cd zyrotrip
npm install
`

Start the development server:

`ash
npm run dev
`

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 🛠️ Tech Stack

- **Framework:** Next.js 15 (App Router, Server Components)
- **Styling:** Tailwind CSS & Framer Motion
- **Database:** SQLite & Prisma ORM
- **Authentication:** NextAuth.js
- **Emails:** React Email & Resend
- **Icons:** Lucide React
